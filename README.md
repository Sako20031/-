# Скиллы для Claude

Личная библиотека скиллов. Подключайте этот репозиторий к сессии Claude Code, и Claude
сам прочитает `CLAUDE.md`, поймёт, какой скилл нужен под задачу, и установит инструменты.

| Скилл | Для чего | Источник |
|---|---|---|
| `chatmonteur` | Монтаж видео: нарезка по смыслу, субтитры, графика, звук | [ArtCog/chatmonteur](https://github.com/ArtCog/chatmonteur) (MIT) |
| `graft` | Граф кода репозитория: быстрый поиск и понимание кода | [trailhq/graft](https://github.com/trailhq/graft) (MIT) |
